# 모델 고르기·호출 수·비용

이 문서는 엔진이 모델을 고르는 방식, 공급자로 보내는 값, 흐름별 호출 수, 사용량 기록과 비용 어림을 설명한다. 연결 방법, 과정과 급의 표, 최신 모델 고르기는 [연결 가이드](../guide/connect-ai.md)에 있다.

## 모델을 고르는 곳

- 노드는 모델을 고르지 않는다. 엔진의 모델 입구(`app/tutor/llm/client.py`)가 요청의 task 이름을 과정에 맞춰 급과 추론 정도를 고른다(`app/tutor/llm/themes.py`).
- 과정은 10개다. 과정마다 기본 급, 기본 추론 정도, 바꾸는 방법은 [연결 가이드의 '과정과 급'](../guide/connect-ai.md#과정과-급)에 있다.
- 이름이 `.judge`나 `.check_code`로 끝나는 task는 '판정' 과정으로 간다. 표에 없는 task는 '대화' 과정으로 간다.

## 공급자로 보내는 값과 다시 보내기

- Claude: 추론 정도는 `output_config.effort`로 보낸다. 샘플링 값은 보내지 않는다. `max_tokens` 기본값은 16,000이다. 출력 상한이 1,024보다 작은 요청에는 생각 몫 2,048을 더한다. 구독 로그인은 쓰지 않고 API 키만 쓴다.
- OpenAI 키: Responses API로 보내고 `reasoning.effort`와 `store: false`를 쓴다. ChatGPT 로그인은 `https://api.openai.com/v1/responses`에 `store: false`, `stream: true`로 보내고 추론 정도는 같은 값을 쓴다.
- 제한 시간은 기본 60초이며 `ALGOBLOCK_LLM_TIMEOUT`으로 바꾼다.
- JSON 모양이 깨진 답은 한 번 더 보낸다. 글로 받는 요청은 다시 보내지 않는다.
- HTTP 408, 409, 429, 500, 502, 503, 504, 529는 제한 시간 안에서 두 번까지 다시 보낸다. 대기는 1초, 2초이고 `retry-after`가 있으면 최대 5초까지 따른다. 401과 403은 키 오류다.

## 프롬프트 캐시

- 엔진은 고정된 앞부분의 글자 수(`cache_prefix`)를 메시지에 붙인다. 바뀌는 내용은 뒤에 둔다.
- Claude: 그 경계에서 글을 두 블록으로 나누고 앞 블록에 ephemeral 캐시를 붙인다. 기본 유지 시간은 5분이고, `ALGOBLOCK_LLM_CACHE_TTL=1h`면 1시간이다.
- OpenAI 키와 ChatGPT 로그인: 앞부분의 해시를 `prompt_cache_key`로 보내 자동 캐시를 쓴다.
- 경계가 있는 프롬프트는 대화, 말 판정, 블록 코드 판정, 꼬리질문, 블록 채우기, 계획 4종, 디버그 3종이다. 해설과 피드백 분석에는 경계가 없다.

## 흐름별 모델 호출 수

- 문제 그림 읽기: 장마다 1회, 실패하면 1회 더(최대 2회). 그래도 실패하면 tesseract로 읽는다.
- 계획(문제 하나 준비): 뼈대 1회(있으면 0회), 사용자 코드의 채점 기준 1회(코드가 있을 때), 풀이 가이드 1–3회(채점에서 틀리면 한 급 올려 다시: 작음 → 가운데 → 큼. 풀이 가이드 과정의 급이 가운데 이상이면 첫 다시 풀기는 그 급 그대로. 정석 가이드가 있으면 0회), 등록 문제 대조(단순 풀이 1회, 입력 생성기 1회, 다르면 가운데 급과 큰 급으로 한 번씩 다시 풀기, 추가 호출 상한 5회. 예시를 맞히려고 다시 푼 호출은 상한에 넣지 않는다), 같은 구조 판정 0–1회, 블록 나누기 1–2회, 힌트 다시 받기 0–1회. 기본 문제(Python)는 미리 만든 계획을 넣어 0회다.
- 등록 문제의 준비는 서버가 두 걸음으로 나눈다. 1걸음은 위의 계획에서 대조를 뺀 호출이고, 2걸음은 대조 호출이다. 튜터 시작은 1걸음만 기다린다. 2걸음이 가이드를 바꿔 끼우면 계획을 다시 짜므로 뼈대와 풀이 가이드를 뺀 계획 호출(같은 구조 판정, 블록 나누기, 힌트)이 한 번 더 든다.
- 대화 한 턴: 블록을 여는 말이나 내용 없는 답은 저장 힌트로 0회다. 내용 있는 말은 판정 1회(출력 상한 16토큰)와 질문 1회다. 내용 없는 짧은 말과 근거·정리 질문의 답은 판정 0회다. 블록 코드 확인은 실행 판정 0회이고, 채점 함수가 없거나 실행으로 가리지 못하면 판정 1회다.
- 블록 채우기: 계획에 코드가 있으면 0회, 없으면 1회. 꼬리질문: 1회.
- 해설: 처음 1회, 그 뒤에는 저장된 해설을 쓰므로 0회. 피드백: 한 번 받을 때 모델은 많아야 두 번(채점 기준 1회, 분석 1회)이다. 같은 제출이면 0회. 계획이 아직 없으면 위의 계획 호출이 먼저 붙는다.
- 디버그: 새 코드면 진단 1회, 처음 증상 질문은 정해진 글이라 0회, 사용자 말에 대한 질문 1회. 같은 코드에 말이 있으면 판정과 질문 각 1회.
- 0회인 것: 학습 보고서, 다음 문제 고르기, 케이스 찾기, 채점, 블록 모으기.

## 사용량 기록

- 서버는 데이터 폴더의 `usage.jsonl`에 호출마다 한 줄을 쓴다. 메모리에는 최근 2,000줄만 둔다.
- 한 줄에는 `at`, `task`, `model`, `effort`, `seconds`, `retry`, `input`, `cache_read`, `cache_write`, `output`이 든다. 키와 프롬프트 글은 적지 않는다.
- Claude는 입력 토큰(캐시 제외), 캐시 읽기, 캐시 쓰기를 그대로 적는다. OpenAI는 입력 토큰에서 캐시 토큰을 뺀 값과 캐시 토큰을 적고, 캐시 쓰기는 0이다.
- 문제를 넣거나 열 때의 준비 호출(그림 읽기, 계획)도 같은 파일에 과정 이름과 함께 남는다.
- 개발용 연결(`ALGOBLOCK_UI_CLIENT=cli`, 이 PC의 Claude Code)의 호출은 `cli/haiku`·`cli/sonnet`·`cli/opus`로 남는다. 구독으로 돌아 금액이 없으므로 비용 어림에서 금액은 0이다.
- 환경 변수 `ALGOBLOCK_LLM_PROMPT_DIR`를 정하면 보낸 프롬프트와 받은 답 전체를 호출마다 파일로 남긴다. 기본값은 꺼짐이며, 데이터 폴더 안을 가리키면 서버가 끈다.

## 비용 어림

- 도구는 `app/tutor/eval/cost.py`다. `usage.jsonl`을 입력으로 받아 흐름별과 과정별 호출 수, 토큰, 캐시 적중률, 어림 금액을 낸다.

```bash
python3 tutor/eval/cost.py <usage.jsonl> [--flows flows.jsonl]   # app 폴더에서
```

- 캐시 적중률 = 캐시 읽기 ÷ (새 입력 + 캐시 읽기 + 캐시 쓰기).
- 아래 단가는 `cost.py`의 `PRICES`에 적힌 값이다(USD, 100만 토큰당).

| 모델 | 새 입력 | 캐시 쓰기(5분) | 캐시 읽기 | 출력 |
|---|---|---|---|---|
| Haiku 5.5 | 0.10 | 0.125 | 0.01 | 0.50 |
| Sonnet 5.5 | 2.00 | 2.50 | 0.10 | 10.00 |
| Opus 5.5 | 4.00 | 5.00 | 0.20 | 20.00 |

- 출처는 `cost.py` 주석에 적힌 Anthropic 공개 가격표 `https://platform.claude.com/docs/en/about-claude/pricing`이고, 확인일은 `PRICED_AT = "2026-11-13"`이다. Haiku 단가는 프롬프트 10만 토큰 이하 기준이다.
- 도구는 5분 캐시 쓰기 단가만 가진다. OpenAI 모델은 단가를 넣지 않아 금액 칸이 빈다. 한 묶음에 단가 없는 호출이 하나라도 있으면 그 묶음의 금액도 빈다.

## 알려진 한계

- 어림 금액은 `cost.py`에 고정된 단가로 계산한다. 공급자의 지금 가격과 다를 수 있다.
