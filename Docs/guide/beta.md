# 베타로 써 보기

이 문서는 AlgoBlock을 베타로 써 보는 사람이 볼 것을 모은다. 설치, 연결, 한계의 자세한 내용은 각 문서를 가리킨다.

## 범위

- macOS(Apple Silicon)가 주 대상이다. Windows 실행 파일도 받을 수 있지만 실제 Windows PC에서 넓게 확인하지 못했다.
- AI 연결은 Claude API 키나 OpenAI API 키를 권한다. ChatGPT 로그인은 미리 보기 단계이고 실제 계정으로 끝까지 확인하지 않았다.

## 시작하기

1. [설치](install.md)를 따라 설치 파일을 받는다.
2. 처음 열 때 뜨는 경고는 [설치](install.md)의 처음 여는 법대로 허용한다. 설치 파일에 서명이 없어서 뜨는 경고다.
3. 튜터를 쓰려면 [AI 연결](connect-ai.md)대로 키를 넣는다. 키가 없어도 문제 풀기, 채점, 기본 문제의 힌트와 해설, 학습 보고서는 된다.
4. 푸는 방식과 화면은 [풀기](solve.md)에 있다.

## 알아 둘 것

- 채점할 코드(직접 적은 코드와 튜터가 만든 코드)를 격리하지 않고 사용자 권한으로 실행한다. 출처를 모르는 코드는 넣지 않는다. 자세한 내용은 [보안 구조](../architecture/security.md)에 있다.
- AI 요금은 사용자가 넣은 키의 계정으로 나간다. 잰 비용은 README의 [AI 비용](../../README.md#ai-비용)에 있다. 공급자 콘솔에서 사용 한도를 걸어 두면 예상보다 많이 쓰는 것을 막을 수 있다.
- 문제, 코드, 대화, 학습 기록은 이 기기의 데이터 폴더에만 있다. 기기 밖으로 나가는 요청은 README의 [개인정보](../../README.md#개인정보)에 있다.
- 그 밖의 한계는 README의 [알려진 한계](../../README.md#알려진-한계)에 있다.

## 알려 주기

- 써 본 느낌, 헷갈린 화면, 튜터의 말이 이상했던 순간은 이슈의 **베타 피드백** 양식으로 남긴다.
- 앱이 기대와 다르게 움직이면 **버그 신고** 양식을 쓴다.
- 보안 문제는 공개 이슈가 아니라 [비공개 취약점 신고](../../.github/SECURITY.md)로 알린다.
- 로그나 화면을 붙일 때 API 키와 토큰은 지운다.
