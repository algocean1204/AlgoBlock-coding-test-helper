# AI 연결

이 문서는 튜터에 AI를 연결하는 방법, 연결을 고르는 순서, 키를 읽고 저장하는 방식, 과정별 모델 급을 설명한다.

## 키 없이 되는 것

- 문제 풀기, 채점, 기본 문제의 힌트와 해설, 학습 보고서는 AI 없이 된다.
- AI가 없으면 '튜터와 차례로'와 '튜터의 질문으로' 카드가 잠긴 채 보인다. 카드 아래에 "튜터 둘은 AI를 연결하면 쓸 수 있어요."라고 적힌다.
- '틀린 곳 같이 찾기'와 '피드백 받기' 단추는 보이지 않는다.
- 등록한 문제의 힌트와 해설, 풀이 가이드와 블록 준비는 AI가 있어야 한다.
- 문제 그림은 AI가 연결돼 있으면 모델이 읽는다. 모델이 두 번 읽지 못한 장이나 연결이 없을 때는 이 기기의 글자 읽기(tesseract)로 읽고, 그렇다고 알린다. [내 문제 넣기](add-problem.md)를 본다.

## 연결 셋

| 연결 | 화면 이름 | 준비하는 것 | 요청을 보내는 주소 |
|---|---|---|---|
| Claude API 키 | "Claude API 키" | `ANTHROPIC_API_KEY` | `https://api.anthropic.com/v1/messages` |
| OpenAI API 키 | "OpenAI API 키" | `OPENAI_API_KEY` | `https://api.openai.com/v1/responses` |
| ChatGPT 로그인 | "ChatGPT 로그인" | 브라우저에서 로그인 | `https://api.openai.com/v1/responses` |

- Claude는 API 키로만 연결한다. 구독 로그인은 없다.
- OpenAI 계열 요청은 `store: false`로 보낸다.
- ChatGPT 로그인은 처음에 `dynamic_agent_client`로 등록하고, 받은 client id를 저장해 다음부터 그것을 쓴다.
- 개발용으로 이 PC의 Claude Code(`claude -p`)를 쓸 수 있다. [개발 환경 만들기](../contributing/dev-setup.md)의 `ALGOBLOCK_UI_CLIENT`를 본다.

### ChatGPT 로그인 하기

1. '연결' → 'ChatGPT 요금제 쓰기'의 "ChatGPT로 로그인"을 누른다.
2. "브라우저에서 로그인 열기" 링크를 누르고 브라우저에서 로그인한다.
3. 성공하면 브라우저에 "연결됐어요. 이 창을 닫고 AlgoBlock으로 돌아가 주세요."가 뜬다.

계정의 워크스페이스나 플랜에 따라 OpenAI 동의 화면이 "필수 권한을 사용할 수 없습니다. 현재 워크스페이스와 플랜으로 계속할 수 없습니다."를 띄울 수 있다. 이 계정으로는 연결할 수 없으니 API 키를 쓴다. 그 화면에서 취소하거나 그대로 계속하면, 앱은 연결하지 못했다는 안내와 함께 이 경우를 알린다.

로그인 대기는 5분까지다. 토큰은 데이터 폴더의 `auth/chatgpt.json`에 권한 0600으로 저장한다. 요청할 때 토큰 만료까지 2분이 남지 않았으면 먼저 갱신한다. 예전 방식으로 로그인했던 사람은 다시 로그인해야 한다(예전 토큰 파일은 읽지 않는다).

## 어느 연결을 쓰나

1. `ALGOBLOCK_LLM_PROVIDER`(`claude`, `chatgpt`, `openai`)가 있으면 그 연결을 쓴다.
2. 없으면 Claude 키 → ChatGPT 로그인 → OpenAI 키 순서로 있는 것을 쓴다. 셋 다 없으면 `claude`로 정한다.

화면 머리에 보이는 연결 이름도 2번의 순서로 정한다. 연결이 없으면 "연결 안 됨"이 보인다. 키, ChatGPT 로그인, 개발용 CLI 가운데 하나라도 있으면 연결된 것으로 본다.

## 키 넣기와 저장

- 오른쪽 위 '연결' → 'AI 연결' 창의 'API 키'에서 "Claude 키" 또는 "OpenAI 키"를 고른다. 키를 붙여 넣고 "키 넣기"를 누른다.
- 키 칸은 가려진 입력이다. 키는 한 줄이고 400자 이하여야 한다.
- 키의 꼴을 저장하기 전에 본다. Claude 키는 `sk-ant-`로, OpenAI 키는 `sk-`로 시작하고 영문·숫자·`-`·`_`만 있어야 한다. OpenAI 칸에 `sk-ant-`로 시작하는 키를 넣어도 받지 않는다. 맞지 않으면 저장하지 않고 까닭을 알린다(넣은 값은 글에 싣지 않는다). 이 검사는 `.env`나 환경 변수로 준 키에는 하지 않는다.
- 키 칸 위에는 고른 공급자의 이름표("Claude API 키")와 안내가 있다. 안내는 키가 어떻게 시작하는지(`sk-ant-`, `sk-`)와 키를 받는 공식 콘솔 링크다(Claude는 `console.anthropic.com/settings/keys`, OpenAI는 `platform.openai.com/api-keys`). 칸 옆의 "보기"와 "숨기기" 단추로 넣은 글을 보거나 가릴 수 있다.
- 키 칸 아래 한 줄이 상태를 알려 준다. 비어 있을 때는 키가 어떻게 시작하는지, 입력하는 동안에는 꼴이 맞는지 바로 보여 준다.
- "키 넣기"를 누르면 그 공급자의 공식 주소에 모델 목록 조회를 한 번 보내 키가 쓸 수 있는지 본다. 요금이 들지 않고 시간 한도는 10초다. 다시 보내지 않고 리다이렉트도 따라가지 않는다. 결과에 따라 이렇게 한다.
  - 200, 쓸 수 있음: 저장하고 "쓸 수 있는 키예요. 저장했어요."를 보인다.
  - 401, 키가 틀림: 저장하지 않고 까닭을 보인다. "그래도 저장"도 없다.
  - 429, 키는 맞지만 지금 요청 한도에 걸림: 저장하고 "키는 맞아요. 지금은 요청 한도에 걸려 있어요."를 노란색으로 보인다.
  - 403, 모델 목록을 볼 권한이 없음: 저장하지 않고 권한을 확인하라고 알린다. "다시 시도"나 "그래도 저장"을 고를 수 있다.
  - 5xx와 529, 공급자 서버가 답하지 않음: 저장하지 않고 "서버가 답하지 않아 확인하지 못했어요"라고 알린다. "다시 시도"나 "그래도 저장"을 고를 수 있다.
  - 연결하지 못함(네트워크, 시간 초과, 리다이렉트, 그 밖의 응답): 확인하지 못했다고 알린다. "다시 시도"나 "그래도 저장"을 고를 수 있다.
  - "그래도 저장"으로 저장한 키는 튜터를 처음 부를 때 다시 확인한다.
- 확인하는 동안에는 "키 넣기"와 공급자 선택이 잠긴다. 공급자를 바꾸면 그 공급자의 상태가 보인다.
- 확인 요청은 `https://api.anthropic.com/v1/models`(Claude)와 `https://api.openai.com/v1/models`(OpenAI)로만 간다. 주소는 환경 변수로 바꿀 수 없다. 키 값은 응답, 로그, 오류 글에 남기지 않는다.
- 안내 문구는 "키는 이 기기에만 저장해요. 다음에 켜도 그대로 쓸 수 있어요."이다.
- 키는 데이터 폴더의 `keys.json`에 저장한다. 권한은 0600이다. Windows는 권한 비트를 쓰지 않는다.
- 넣은 키는 실행 중인 앱에 바로 올라간다. 화면의 응답에는 키 값이 없고 "넣음" 여부만 있다.
- 넣은 키를 지우려면 '연결'에서 그 공급자를 고르고 "넣은 Claude 키 지우기"(또는 OpenAI)를 누른 뒤 확인에서 "지우기"를 누른다. `keys.json`에서 그 공급자의 항목만 지우고 다른 공급자의 키는 그대로 둔다. `.env`나 환경 변수로 준 키는 지우지 않는다. 지운 뒤에도 그런 키가 있으면 그 키로 계속 연결된 상태이고, 화면이 그렇게 알린다.
- 키는 그 AI 서비스의 API에 보낼 때만 쓴다. 위 표의 요청 주소와 모델 목록 주소(`/v1/models`)다.

## 키를 읽는 순서

서버가 켜질 때 아래 순서로 찾는다. 먼저 찾은 값은 뒤의 값이 덮지 않는다.

1. 환경 변수
2. 저장소 루트의 `.env`
3. 데이터 폴더의 `.env`
4. 데이터 폴더의 `keys.json`

`.env`에서는 `ANTHROPIC_API_KEY`와 `OPENAI_API_KEY` 두 이름만 읽는다. 저장소의 `.env.example`을 `.env`로 복사해 쓸 수 있다. 그 연결의 키 환경 변수가 없으면 `ALGOBLOCK_LLM_API_KEY`를 본다.

## 키가 맞지 않을 때

- AI 서비스가 401이나 403을 주면 "모델 키가 맞지 않아요. '연결'에서 키를 다시 넣어 주세요."가 뜬다. 머리 표시는 "키 확인 필요"가 된다.
- AI 서비스가 429를 주면 "모델 사용 한도에 걸렸어요. 잠시 뒤에 다시 해 주세요."가 뜬다.

## 과정과 급

튜터의 일은 과정 여덟 개로 나뉜다. 과정마다 급과 추론 정도를 따로 정한다. 급은 '작음', '가운데', '큼' 셋이다. 추론 정도는 '낮음', '보통', '높음' 셋이다.

| 과정 (화면 이름) | 환경 변수 | 기본 급 | 기본 추론 정도 | 언제 돈다 |
|---|---|---|---|---|
| 문제 읽기 | `ALGOBLOCK_THEME_READ` | 가운데 | 높음 | 문제를 넣을 때 이미지의 글을 읽는다 |
| 풀이 가이드 | `ALGOBLOCK_THEME_GUIDE` | 가운데 | 높음 | 문제를 넣을 때 한 번, 문제의 뼈대와 정답 코드를 만든다 |
| 블록 설계와 힌트 | `ALGOBLOCK_THEME_BLOCKS` | 가운데 | 높음 | 문제를 넣을 때 한 번, 풀이를 블록으로 나누고 힌트 질문을 만든다 |
| 대화 | `ALGOBLOCK_THEME_TALK` | 작음 | 낮음 | 튜터가 매번 건네는 말 |
| 판정 | `ALGOBLOCK_THEME_JUDGE` | 작음 | 낮음 | 내 답과 블록 코드가 맞는지 보는 짧은 판정 |
| 해설 | `ALGOBLOCK_THEME_EXPLAIN` | 작음 | 보통 | 튜터의 해설 |
| 피드백 | `ALGOBLOCK_THEME_FEEDBACK` | 작음 | 보통 | 제출 뒤의 피드백 |
| 디버그 진단 | `ALGOBLOCK_THEME_DEBUG` | 작음 | 보통 | 틀린 코드에서 원인이 있는 줄 찾기 |

- 큰 급은 어느 과정의 기본값도 아니다.
- 급은 연결에 따라 모델 시리즈에 대응한다. Claude는 Haiku, Sonnet, Opus 시리즈를 쓴다. OpenAI 키와 ChatGPT 로그인은 Luna, Terra, Sol 시리즈를 쓴다.

### 과정별 모델 바꾸기

- '연결' → '더 정하기' → '과정별 모델' → "과정별 모델 설정" 순서로 연다.
- 과정마다 모델과 추론 정도를 고르면 바로 저장된다. 바뀐 과정에는 "기본값으로" 단추가 생긴다.
- 저장되는 것은 급과 추론 정도다. 모델 이름은 저장하지 않는다. 그래서 연결을 바꿔도 고른 급이 그대로 간다.
- 값이 덮이는 순서는 기본값 → 사용자 선택 → `ALGOBLOCK_THEME_<과정>=모델:정도`(예: `ALGOBLOCK_THEME_JUDGE=claude/claude-sonnet-5-5:low`) → `ALGOBLOCK_LLM_MODEL`이다. 뒤의 것이 이긴다. `ALGOBLOCK_LLM_MODEL`을 설정하면 모든 과정이 그 모델을 쓰고, 화면에 그 사실이 뜬다.

## 시리즈의 최신 모델 고르기

- 키나 ChatGPT 로그인으로 연결했을 때만 AI 서비스의 모델 목록을 받는다. 하루에 한 번까지 다시 받는다. 결과와 받은 시각은 데이터 폴더의 `models.json`에 저장한다.
- 이름 꼴이 맞는 것만 본다. Claude는 `claude-(haiku|sonnet|opus)-큰수[-작은수]`, OpenAI는 `gpt-큰수[.작은수]-(luna|terra|sol)` 꼴이다. 날짜가 붙은 스냅숏과 미리보기 이름은 고르지 않는다.
- 시리즈마다 (큰 수, 작은 수)가 가장 큰 이름을 고른다.
- 목록을 받지 못하면 아래 이름을 쓴다. 오프라인, 권한 없음이 여기에 해당한다.
  - Claude: `claude-haiku-5-5`, `claude-sonnet-5-5`, `claude-opus-5-5`
  - OpenAI: `gpt-6-luna`, `gpt-6.1-terra`, `gpt-6.1-sol`
- 화면 이름은 Claude가 "Sonnet 5.5"처럼, OpenAI가 "Terra (GPT-6.1)"처럼 보인다.
- `ALGOBLOCK_UI_PREPARE=0`이면 목록을 받지 않는다.

비용은 [모델과 비용](../architecture/models-and-cost.md)에서 본다.

## 알려진 한계

- ChatGPT 연결은 미리 보기 단계라 바뀔 수 있다. 로그인부터 튜터 응답까지 전 과정이 끝까지 되는지는 확인하지 않았다.
- 목록을 받지 못하면 표의 이름을 쓴다. 그 이름이 지금 나온 최신 모델과 같다고 보장하지 않는다.
